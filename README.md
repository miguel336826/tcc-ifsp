# Trabalho de Conclusão de Curso
## Matemágico: Aprenda Matemática

### TCC - IFSP Campus Araraquara

**Status do projeto:** Defendido / Pronto.

## 📄 Sobre o Projeto
Este repositório contém o código-fonte do sistema desenvolvido para o Trabalho de Conclusão de Curso intitulado **"Matemágico: Aprenda Matemática"**, apresentado ao curso de Técnico em Informática do IFSP Campus Araraquara.

  O objetivo deste projeto é oferecer uma plataforma para axiliar alunos no aprendizado de matemática, através de documentos explicativos, testes, videoaulas, entre outros.

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **Linguagens:** PHP, JavaScript, HTML/CSS.
* **Framework Frontend:** Bootstrap.
* **Banco de Dados:** MySQL.
* **Outras ferramentas:** Microsoft Azure (Deploy).
* **Plataformas de desenvolvimento:** Visual Studio Code, PHPMyAdmin (local), XAMPP.
